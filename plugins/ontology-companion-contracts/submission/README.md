# Submission routes and historical MCP preparation

The initial distribution route is a **skills-only ZIP** containing the skill and its required offline runtime, schema assets, and examples. Current public artifacts, submission, review, and publication outcomes are tracked in [release-state.json](../release-state.json). User authorization to publish does not itself establish acceptance or Directory publication.

[chatgpt-app-submission.json](../chatgpt-app-submission.json) and [IMPLEMENTATION_REVIEW.md](IMPLEMENTATION_REVIEW.md) are **historical local implementation drafts from 2026-09-05** for three MCP tools and five positive/three negative review cases. Their `not submission-ready` assessment applies to that hosted MCP route at that checkpoint, not to the current skills-only ZIP route.

Those drafts do not establish a public MCP endpoint, hosted ChatGPT execution, production authentication, or platform review. Do not use them as the current skills-only submission metadata or upload them as an implemented hosted connector. A future submission that includes MCP requires fresh live transport, metadata, permission, and host verification.

The local Codex stdio test, complete skills-only package, and any future hosted MCP deployment are separate evidence tracks. Read the [current release state](../release-state.json) rather than inferring current publication from an older review document.
