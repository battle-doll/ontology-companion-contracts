# Ontology Companion Contracts

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Русский](README.ru.md)

**Предварительная версия P1a · [Текущий статус публикации и проверок](release-state.json)**

Проверяйте документы обмена онтологиями по явно поддерживаемому контракту и получайте детерминированные структурированные сообщения об ошибках. Ontology Companion Contracts разрабатывается как набор версионируемых контрактов и самостоятельный публичный плагин проверки.

Локальная программа проверяет черновой конверт обмена и отдельные профили Code/Context без сети. Она читает явно выбранный JSON и выводит структурированный результат; также реализован дополнительный stdio-адаптер для ручной настройки хоста. Локальные синтетические тесты пройдены. В macOS с Codex 0.153.3 также пройдена базовая проверка вручную настроенного локального stdio на явно помеченных тестовых артефактах. Интеграция с размещённым ChatGPT, установка через маркетплейс плагинов и публикация в Directory, а также настоящее одобрение человеком не проверены. Выполнение миграций и работа с реальными данными в промышленной эксплуатации пока не поддерживаются.

## Установка публичной предварительной версии

Когда предварительная версия репозитория станет доступна, установите полный пакет через Codex CLI с поддержкой плагинов:

```sh
codex plugin marketplace add battle-doll/ontology-companion-contracts
codex plugin add ontology-companion-contracts@ontology-contracts-preview
```

В новой задаче Codex вызовите `$validate-ontology-contract` и попросите проверить `examples/context-decision.json` из установленного пакета. Сохраняйте весь пакет: одного `SKILL.md` недостаточно без исполняемого кода и файлов схем. Для этой проверки плагины Code и Context не нужны.

[Быстрый старт для Windows](docs/WINDOWS_QUICKSTART.md) · [Текущий статус выпуска](release-state.json). Установка из маркетплейса GitHub и публикация в universal Directory — разные статусы. Приведённые ниже результаты относятся к зафиксированной локальной проверке; последующие результаты публикации и тестов ОС смотрите в файле состояния выпуска.

## Запуск локальной версии

В каталоге этого репозитория используйте Python 3.11 или новее. Для демонстрационных команд дополнительные пакеты Python не нужны. Виртуальное окружение и команды Windows описаны в руководстве по ОС.

```sh
python3 --version
python3 scripts/run.py validate examples/context-decision.json
python3 scripts/check.py
```

Команды запускают локальный код разработки. Они не устанавливают плагин и не создают размещённый сервис. Все примеры синтетические.

## Операционные системы и подтверждение

Целевые ОС: **macOS, Windows и Linux**. Переносимость исходного кода, выполненные тесты ОС и работа хоста плагина подтверждаются отдельно. Этот черновик не заявляет об успешных тестах на всех трёх ОС.

| OS | Подтверждение выполнения |
| --- | --- |
| macOS | Локальные синтетические тесты Python 3.12.14 пройдены |
| Windows | `not_run` — CI настроен, выполнение ожидается |
| Linux | `not_run` — CI настроен, выполнение ожидается |
| Интеграция с хостом плагина | Базовая проверка вручную настроенного локального stdio в macOS с Codex 0.153.3 пройдена; размещённый ChatGPT, маркетплейс/Directory и настоящее одобрение человеком не проверены |

[Руководство для macOS / Windows / Linux](docs/ru/PLATFORMS.md)

## Границы продуктов

Code, Context и Contracts — независимые продукты. Потребители могут закреплять или включать контрактные артефакты без установки плагина Contracts. Это не означает общую БД, наследование прав, автоматический вызов другого плагина или изменение существующего Code.

Успех проверки относится только к фактически выполненным проверкам. Он не доказывает истинность, авторство, права пользователя или поведение во время исполнения. Неподдерживаемые версии остаются неподдерживаемыми, невыполненные слои получают `not_checked`, внешние схемы не загружаются скрыто.
