# Ontology Companion Contracts — リリースとロールバック

設計・契約成果物・ランタイム・ホスト連携・提出・承認・公開を別々に追跡します。一台のテスト成功は三 OS のリリース証拠ではありません。バージョンと digest を固定し、リリース証拠を保持します。公開前にライセンス権利、非公開脆弱性報告、掲げるすべての OS、実際のホスト動作を確認します。コードのロールバックにはデータと契約の互換計画が必要です。

ローカルランタイムは、ドラフトの交換 envelope と個別の Code/Context プロファイルをオフラインで検証します。明示的に選んだ JSON を読み、構造化結果を出力します。ホストへ手動設定する任意の stdio アダプターも実装済みです。ローカル合成テストは成功しています。公開プラグインのインストール、移行実行、実データの利用、実際のホスト連携は未対応または保留です。
