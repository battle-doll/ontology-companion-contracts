# Ontology Companion Contracts — 架构与路线图

Contracts 共享版本化产物，各产品负责自己的工作流与权限。Context 预览是本地合成消费者，Contracts 预览是确定性离线检查器。可信批准宿主、生产存储、公开插件与可选 Code 连接属于后续关卡。只有两个真实消费者证明需求一致后才提取共享执行核心。

本地运行时离线验证交换 envelope 草案及独立的 Code/Context 配置规范。它读取明确选择的 JSON 并输出结构化结果，也已实现可在宿主中手动配置的可选 stdio 适配器。本地合成测试已通过。公开插件安装、实际迁移执行、真实数据使用及实际宿主集成仍不受支持或待完成。
