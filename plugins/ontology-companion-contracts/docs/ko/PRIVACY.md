# Ontology Companion Contracts — 개인정보

현재 프리뷰에는 합성 데이터만 사용합니다. 실제 대화·인증 정보·개인 기록·비공개 소스를 예제나 로그·이슈에 넣지 않습니다. 로컬 코어는 텔레메트리나 외부 모델 보강을 전제로 하지 않습니다. 호스트에 붙여 넣은 자료에는 호스트의 처리 규칙이 별도로 적용됩니다. 로컬 삭제로 호스트 기록·백업·기존 내보내기까지 지워진다고 보장하지 않습니다.

로컬 런타임은 교환 envelope 초안과 별도 Code/Context 프로필을 오프라인으로 검증합니다. 명시적으로 선택한 JSON 파일을 읽고 구조화 결과를 출력하며, 호스트에 수동 설정할 수 있는 선택적 stdio 어댑터도 구현했습니다. 로컬 합성 시험을 통과했습니다. 공개 플러그인 설치·실제 이관 실행·실제 데이터 사용·실제 호스트 연동은 미지원 또는 대기 상태입니다.
