# Ontology Companion Contracts — Архитектура и план

Contracts предоставляет версионируемые артефакты; каждый продукт управляет собственным процессом и правами. Context — локальный синтетический потребитель, Contracts — детерминированный автономный валидатор. Доверенное одобрение хоста, промышленное хранение, публичные плагины и дополнительный мост Code относятся к следующим этапам. Общее исполняемое ядро извлекается только после подтверждения одинаковых требований двумя реальными потребителями.

Локальная программа проверяет черновой конверт обмена и отдельные профили Code/Context без сети. Она читает явно выбранный JSON и выводит структурированный результат; также реализован дополнительный stdio-адаптер для ручной настройки хоста. Локальные синтетические тесты пройдены. Установка публичного плагина, выполнение миграций, реальные данные и фактическая интеграция с хостом пока не поддерживаются или ожидаются.
