# Ontology Companion Contracts — 发布与回滚

分别跟踪设计、契约产物、运行时、宿主集成、提交、批准及发布。单机测试通过并非三系统发布证据。固定版本与 digest，保留不可变的发布证据。公开前确认许可权利、私密安全报告、所有宣传支持的系统及实际宿主工作流。代码回滚需要经审查的数据和契约兼容方案。

本地运行时离线验证交换 envelope 草案及独立的 Code/Context 配置规范。它读取明确选择的 JSON 并输出结构化结果，也已实现可在宿主中手动配置的可选 stdio 适配器。本地合成测试已通过。公开插件安装、实际迁移执行、真实数据使用及实际宿主集成仍不受支持或待完成。
