# Ontology Companion Contracts — 구조와 로드맵

Contracts는 버전별 계약 산출물을 공유하고 각 제품은 자체 작업 흐름과 권한을 관리합니다. Context 프리뷰는 로컬 합성 소비자, Contracts 프리뷰는 결정론적 오프라인 검사기입니다. 신뢰할 수 있는 승인 호스트·운영 저장소·공개 플러그인·선택적 Code 연결은 후속 단계입니다. 실제 두 소비자의 같은 요구가 입증된 뒤에만 실행 코어를 추출합니다.

로컬 런타임은 교환 envelope 초안과 별도 Code/Context 프로필을 오프라인으로 검증합니다. 명시적으로 선택한 JSON 파일을 읽고 구조화 결과를 출력하며, 호스트에 수동 설정할 수 있는 선택적 stdio 어댑터도 구현했습니다. 로컬 합성 시험을 통과했습니다. 공개 플러그인 설치·실제 이관 실행·실제 데이터 사용·실제 호스트 연동은 미지원 또는 대기 상태입니다.
