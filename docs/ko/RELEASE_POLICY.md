# Ontology Companion Contracts — 출시와 롤백

설계·계약 산출물·런타임·호스트 연동·제출·승인·게시 상태를 각각 관리합니다. 한 컴퓨터의 시험 통과는 세 OS 출시 증거가 아닙니다. 버전과 digest를 고정하고 출시 증거를 보존합니다. 공개 전 라이선스 권리·비공개 보안 신고·광고하는 모든 OS·실제 호스트 흐름을 확인합니다. 코드 롤백에는 호환되는 데이터·계약 계획이 필요합니다.

로컬 런타임은 교환 envelope 초안과 별도 Code/Context 프로필을 오프라인으로 검증합니다. 명시적으로 선택한 JSON 파일을 읽고 구조화 결과를 출력하며, 호스트에 수동 설정할 수 있는 선택적 stdio 어댑터도 구현했습니다. 로컬 합성 시험을 통과했습니다. 공개 플러그인 설치·실제 이관 실행·실제 데이터 사용·실제 호스트 연동은 미지원 또는 대기 상태입니다.
