# Ontology Companion Contracts — 構成とロードマップ

Contracts はバージョン付き成果物を共有し、各製品が自身のワークフローと権限を管理します。Context プレビューはローカル合成消費者、Contracts プレビューは決定的なオフライン検証器です。信頼できる承認ホスト、本番保存、公開プラグイン、任意の Code 連携は後続段階です。実際の二つの消費者が同じ要件を実証してから実行コアを抽出します。

ローカルランタイムは、ドラフトの交換 envelope と個別の Code/Context プロファイルをオフラインで検証します。明示的に選んだ JSON を読み、構造化結果を出力します。ホストへ手動設定する任意の stdio アダプターも実装済みです。ローカル合成テストは成功しています。公開プラグインのインストール、移行実行、実データの利用、実際のホスト連携は未対応または保留です。
