# Ontology Companion Contracts — バージョン方針

設計バージョンはランタイムやプラグインのバージョンではありません。schema/profile・validator・消費者を区別し、対応成果物と digest を固定します。互換性には明示的な producer→consumer の組と実行済み fixtures が必要で、番号だけから推測しません。過去のドラフトを保持し、未対応版を拒否します。

ローカルランタイムは、ドラフトの交換 envelope と個別の Code/Context プロファイルをオフラインで検証します。明示的に選んだ JSON を読み、構造化結果を出力します。ホストへ手動設定する任意の stdio アダプターも実装済みです。ローカル合成テストは成功しています。公開プラグインのインストール、移行実行、実データの利用、実際のホスト連携は未対応または保留です。
