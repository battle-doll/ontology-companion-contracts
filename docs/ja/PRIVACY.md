# Ontology Companion Contracts — プライバシー

現プレビューには合成データだけを使用します。実際の会話、認証情報、個人記録、非公開ソースを例・ログ・Issue に含めないでください。ローカルコアはテレメトリーや外部モデルによる補完を前提にしません。ホストへ貼り付けた情報にはそのホストの規則が適用されます。ローカル削除はホスト履歴・バックアップ・既存エクスポートの削除保証ではありません。

ローカルランタイムは、ドラフトの交換 envelope と個別の Code/Context プロファイルをオフラインで検証します。明示的に選んだ JSON を読み、構造化結果を出力します。ホストへ手動設定する任意の stdio アダプターも実装済みです。ローカル合成テストは成功しています。公開プラグインのインストール、移行実行、実データの利用、実際のホスト連携は未対応または保留です。
