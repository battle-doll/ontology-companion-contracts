# Ontology Companion Contracts — Конфиденциальность

В текущей версии используйте только синтетические данные. Не помещайте реальные переписки, учётные данные, личные записи или закрытый код в примеры, журналы и задачи. Локальное ядро не предполагает телеметрию и дополнение внешней моделью. Вставленные в хост сведения обрабатываются по правилам этого хоста. Локальное удаление не гарантирует очистку истории хоста, резервных копий и прежних экспортов.

Локальная программа проверяет черновой конверт обмена и отдельные профили Code/Context без сети. Она читает явно выбранный JSON и выводит структурированный результат; также реализован дополнительный stdio-адаптер для ручной настройки хоста. Локальные синтетические тесты пройдены. Установка публичного плагина, выполнение миграций, реальные данные и фактическая интеграция с хостом пока не поддерживаются или ожидаются.
