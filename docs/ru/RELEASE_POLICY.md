# Ontology Companion Contracts — Выпуск и откат

Отдельно отслеживайте проектирование, контракт, программу, интеграцию с хостом, подачу, одобрение и публикацию. Успех на одном компьютере не подтверждает выпуск для трёх ОС. Закрепляйте версии и digest, храните неизменяемые свидетельства выпуска. До публикации проверьте права на лицензирование, закрытые сообщения о безопасности, все заявленные ОС и реальный процесс хоста. Для отката кода нужен проверенный совместимый план данных и контрактов.

Локальная программа проверяет черновой конверт обмена и отдельные профили Code/Context без сети. Она читает явно выбранный JSON и выводит структурированный результат; также реализован дополнительный stdio-адаптер для ручной настройки хоста. Локальные синтетические тесты пройдены. Установка публичного плагина, выполнение миграций, реальные данные и фактическая интеграция с хостом пока не поддерживаются или ожидаются.
